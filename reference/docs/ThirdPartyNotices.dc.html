Third-party notices — Offline AI NPC

This is a scoped inventory, not a licence grant or clearance of an entire native/model stack. The plugin export contains its own code, configuration and documentation, plus text compatibility sources with their original licences and modification notices. External packages, model weights, Piper and espeak data are installed separately. The exact Windows x64 CPU Qwen native DLL is included as described below. An actual game distribution can include components that the Asset Store package excludes.

The dated source revisions and the model files' expected checksums are in STACK_SOURCE_INVENTORY_2026-10-02.md. An observed source tag, expected weight hash and installed binary hash are different pins. Retain the notices of the exact artifacts you redistribute.

Bundled compatibility source text

Editor/Dependencies/CompatibilityData/ai.undream.llm/ retains the LLMUnity 3.0.3 Apache-2.0 licence, original third-party notices, source revision, exact before/after hashes and modified source text. Editor/Dependencies/CompatibilityData/com.whisper.unity/ retains the whisper.unity 529a MIT copyright/permission notice, source revision, exact before/after hashes and two modified managed source files. Payloads are data files; they do not compile a second SDK when this plugin is imported. Both directories include modification notices. These compatibility-source changes include no model files or SDK native binaries. The separately described Qwen DLL delivery is included in the package. The optional compatibility window applies them only after Preview and an explicit Apply.

Included Qwen native speech library

Plugins/Windows/x86_64/OfflineAINPCQwenNative.dll is the ordinary empty-URL Qwen route. Its delivery manifest identifies 5366978 bytes, SHA256 4de29ccecbb2962452c2c9f2a1a4dbcc49f1c56e50f5aad74cb25a1739d0d9f3, qwentts.cpp 6fae92914045cd83364d2845ceaa0f7969727319 and ggml 40e16e4a814f7fe851a0c486fb9e8c722e957830. This is Windows x64 CPU, eight threads, static ggml, flash attention off and max batch one. It loads and speaks in the Unity Editor and in a built Windows player; no Linux/macOS binary is included.

qwentts.cpp and ggml are MIT. The static MinGW-w64 runtime has its own notices, including winpthreads; GCC runtime code is GPLv3 with Runtime Library Exception 3.1. Preserve all five exact files in Plugins/Windows/x86_64/Notices/: qwentts-LICENSE.txt, ggml-LICENSE.txt, MinGW-w64-runtime.txt, GPL-3.0.txt and GCC-RUNTIME-EXCEPTION.txt. The exception applies under its stated Eligible Compilation Process / Independent Module conditions; it is not a blanket MIT label or the Piper/eSpeak GPL distribution boundary. The talker and codec are separate Apache-2.0 weight downloads, not bytes in this DLL.

Before you redistribute

Before redistributing a chosen stack, record exact binary and model hashes, source/build revisions and patches, licence/copyright/NOTICE copies, and dictionary and preprocessing data. GPL-covered components additionally need a compliant Corresponding Source distribution method.

Of native code this package contains only the named Qwen DLL; it contains no model weights and no espeak data. Keep the DLL's five notices with it in your game's distribution.
