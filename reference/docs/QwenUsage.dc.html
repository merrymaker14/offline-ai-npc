Qwen speech: language, voice and style

In 1.1, choose a ready CustomVoice speaker. Creating your own voice from a description (VoiceDesign) is not part of this version.

For the current Unity Qwen3-TTS component, start with a CustomVoice talker and leave Style empty. For the overall model workflow, see Current model usage. These settings have separate jobs:

SettingWhat it controlsExample
TextWords to sayHello. I am ready.
LanguageLanguage of those wordsUnity code en; runtime label english
VoiceA named preset timbreryan
StyleDelivery instruction, where the model supports itSpeak calmly, at a measured pace.

Describe delivery in Style; set the language separately. A style such as “Speak Russian” does not replace the language setting or translate the text.

Which model accepts which input?

Qwen3-TTS variantVoice inputInstructions
0.6B CustomVoiceNamed preset speakerInstruction control is unsupported; leave Style empty
1.7B CustomVoiceNamed preset speakerOptional delivery instruction
1.7B VoiceDesignDescription of a voiceA separate VoiceDesign operation
0.6B / 1.7B BaseReference audio or a prepared clone promptA separate cloning operation

The bundled native transport explicitly accepts CustomVoice; Base and VoiceDesign are not configured. The optional HTTP request shape also carries a named voice, so it does not provide a VoiceDesign or reference-audio authoring flow. See the official model overview, official Python API.

In Unity

using OfflineAINPC.Speech;

// CustomVoice, with no style dependency:
var line = new SpeechRequest("Hello. I am ready.",
    languageCode: "en", voiceId: "ryan");

// For a separately verified 1.7B CustomVoice setup:
var styledLine = new SpeechRequest("Hello. I am ready.",
    languageCode: "en", voiceId: "ryan",
    style: "Speak calmly, at a measured pace.");

An explicit SpeechRequest.LanguageCode overrides the engine language. Native codes en, ru, es, zh, ja, ko, de, fr, pt, it accept region/script suffixes and _; blank or unknown codes select auto. This is language selection, not translation. The native DLL passes text, language, speaker and optional style directly to the pinned runtime. HTTP field omission/default behavior belongs only to an explicitly configured external server. Leave both engine Style and request Style empty for 0.6B CustomVoice. A 1.7B instruction setup requires its own model and runtime check.

Model Manager downloads the speech model files. The package includes a Windows x64 CPU Qwen native DLL; leave External server URL empty to use it. The ordinary Qwen route needs no manually started HTTP server, executable or compiler setup. Keep an existing working Piper route. See the native speech setup and Licensing.
