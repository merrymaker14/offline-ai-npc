Getting startedFrom import to the first typed answer; add voice and microphone input afterwards. Read Is this for your game? Beginner's guideStart here if you have not installed a Unity package with external dependencies before. The first goal is one typed question and one text answer in Hello NPC. BUILDING WITH IT
Dialogue: wiring a talking characterFor the first answer, install compatible LLM for Unity, download one suitable language model and use Welcome ▸ Open Hello NPC sample. Structured actionsAn NPC reply can carry two things at once: natural speech for the voice, and a machine-reliable decision your game can execute. Which languages does this support?Choose the character's reply language, microphone recognition language and voice language together. Internal state--- Points of interestMake an object noticeable: add AI Point Of Interest to it. That is the whole setup. RecipesFive shapes this plugin is actually good at, with what each one uses and roughly what it costs to build. Agent tools (MCP)The package includes an MCP server that runs inside the Unity editor. The interview demoA five-minute scene where you question a woman across a desk and decide whether to clear her. With a model available, her answers are generated on your machine.
MODELS AND VOICES
Using the current local modelsChoose a catalog text model in the first-dialogue setup. Download missing files in Model Manager. Start with a typed reply, then add Qwen speech or a Whisper microphone. Qwen speech: language, voice and style1, choose a ready CustomVoice speaker. Creating your own voice from a description (VoiceDesign) is not part of this version.
